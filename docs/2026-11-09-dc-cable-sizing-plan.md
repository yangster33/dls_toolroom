# 直流电缆选型 · 页面复用方案（A：现有页面加 DC 模式）

> 分支：`maint/tool-23-cable-sizing`
> 日期：2026-11-09
> 状态：待实施
> 范围：只做直流**电缆选型**；不计算蓄电池、整流器、交流输入和直流系统短路电流

## 1. 背景

现有电缆选型页已经支持 `system = 'dc'`，但只是“AC 表 + DC 压降”：

- 载流量仍按 3 根负载导体的 AC 表取值，直流只有 2 根导体，结果偏保守；
- 没有“直流回路类型”，用户不知道该填负荷电流、充电电流还是放电电流；
- 没有直流专用压降预设和直流保护说明；
- 电缆标签固定 `2×S+1×PE`，没有区分 2 线、2 线+PE、正极接地；
- 没有厂家 DC 载流量表的入口。

目标：在现有页面里加一个**直流电缆选型模式**，默认按国家标准 2 根导体表，可选厂家 DC 表；只回答“这根直流电缆选多大截面、压降和热稳定是否通过”，不扩展到电池/整流器容量。

## 2. 范围

| 做 | 不做 |
|---|---|
| DC 回路类型（负荷/充电/放电/整流器/母线） | 蓄电池容量、放电曲线 |
| 2 根负载导体载流量表（国家标准） | 整流器容量、N+1 配置 |
| 可选厂家 DC 载流量表 | 交流输入电流、AC 配电 |
| 直流压降 `2×I×L×R` | 直流系统短路电流计算（仍由用户输入 Isc） |
| 直流保护配合校核与说明 | DC 断路器/熔断器完整选型 |
| 2 线 / 2 线+PE / 正极接地标签 | 直流系统接地设计、绝缘监测 |
| 计算书 DC 公式与来源标签 | 高压直流（>1.5 kV）专项 |

## 3. 直流回路类型与电流口径

页面只算电缆，电流由用户输入；回路类型只改变标签、提示和默认值，不改变引擎。

| 回路类型 | 页面标签 | 提示 | 典型电流来源 |
|---|---|---|---|
| 负荷回路 | 负荷电流 | 稳态负荷电流，按 `P/U` 或负荷清单 | `I_L = Σ(P_i×K_i)/U` |
| 充电回路 | 充电电流 | 常见 0.1C10，按电池厂家 | `I_ch = k_ch×C10` |
| 放电回路 | 放电电流 | 按最低母线电压 `U_min` | `I_dis = P_L/U_min` |
| 整流器输出 | 整流器输出电流 | 负荷 + 充电，N+1 冗余 | `I_rect ≥ I_L + I_ch` |
| 母线/分路 | 分路电流 | 单路分路电流 | 分路负荷汇总 |

说明：

- 页面不计算 `C10`、`I_ch`、`I_rect`，这些由用户或后续的“直流供电系统”工具算好再填。
- 充电/放电回路的电缆仍按稳态电流选截面；短时放电可按厂家短时载流量校核，本轮不做。
- 直流系统短路电流 `Isc` 仍由用户输入，用于热稳定和保护配合。

## 4. 载流量数据源

### 4.1 默认：国家标准 2 根导体表

- 依据：`GB/T 16895.6-2014 / IEC 60364-5-52` 附录 B。
- 表：B.52.2（PVC，2 根负载导体）、B.52.3（XLPE，2 根负载导体）。
- 覆盖：铜/铝、A1/A2/B1/B2/C/D；E/F/G 自由空气按 2 根导体整理，或直接走厂家表。
- 修正系数沿用现有：温度、成束、土壤热阻率；谐波不适用。
- 数据准备：逐格转录，配黄金用例（固定输入 → 固定截面/载流量）。

> 风险：2 根导体表不在当前仓库里，需要按标准原文转录；如果暂时拿不到原文，先回退到 3 根导体表并明确标注“保守”，不凭记忆填数。

### 4.2 可选：厂家 DC 表

- 入口：`载流量数据源 = 国家标准 / 厂家 DC 表`。
- 形式：16 行可编辑表格，对应当前“材料 + 绝缘 + 敷设方式”组合的 16 个标准截面；也可支持 CSV 粘贴。
- 行为：
  - 选“厂家 DC 表”后，引擎用厂家值替换 `I_table`，其余修正系数不变；
  - 计算书来源标签显示“厂家表”，并记录厂家/表名（可选输入）；
  - 提供“恢复国家标准表”按钮；
  - 厂家表为空或无效时，回退国家标准表并提示。
- 不在本轮做：多厂家表库、按温度/敷设自动查厂家多张表；先支持“当前组合的 16 个数”。

## 5. 直流压降与保护

### 5.1 压降

- 公式：`ΔU = 2 × I × L × R`（正/负两根导体往返）。
- `R` 仍按最高工作温度电阻计算；DC 无稳态电抗，`X` 不参与。
- 允许压降：
  - 预设 3% / 5% / 自定义；
  - 默认 5%，并在页面提示“-48V 直流配电常见 3%–5%，以 YD/T 5040 / GB 51194 或项目规范为准”。
- 压降限值来源标签：`预设` 或 `输入`。

### 5.2 保护

- 本轮只做**配合校核**，不做完整 DC 断路器/熔断器选型。
- 校核仍为 `Ib ≤ In ≤ Iz`；熔断器的 AC `k3` 规则不直接用于 DC，页面标注“DC 熔断器按厂家 I²t/熔化系数复核”。
- 增加 DC 保护提示：
  - 直流断路器需按 DC 电压下的 `Icu/Ics`、极性、L/R 时间常数选型；
  - 电池侧短路电流大，需校核分断能力；
  - 正极接地系统的故障路径与 AC 不同。
- `In` 仍可自动匹配或手动输入；自动匹配只按标准壳架，不区分 AC/DC 产品系列。

## 6. 页面改造（A 方案）

### 6.1 系统与负荷

系统选择为 DC 时：

- 显示“直流回路类型”（负荷/充电/放电/整流器/母线）；
- 显示“导线制式”（2 线 / 2 线+PE / 正极接地）；
- 电压默认 48V，可改 24/110/220/240/380；
- 隐藏“3 次谐波含量”；
- 功率/电流输入的标签随回路类型变化；
- 保留需要系数、效率（按用户口径）。

### 6.2 电缆与敷设

- 材料/绝缘/敷设方式不变；
- 新增“载流量数据源”（国家标准 / 厂家 DC 表）；
- 选厂家表时显示 16 行编辑表 + 厂家/表名（可选）；
- 温度、成束、土壤修正不变；
- 并联根数、线路电抗：DC 下电抗不参与压降，输入可隐藏或置灰。

### 6.3 校核条件

- 允许压降：3% / 5% / 自定义；
- 短路电流 `Isc`：保留；
- 保护动作时间 `t`：保留；
- 保护电器类型：DC 断路器 / DC 熔断器 / 仅校核；
- 电机启动校核：DC 下隐藏；
- 增加“DC 设计提示”：本页只算电缆，不含电池/整流器容量。

### 6.4 结果与计算书

- 电缆标签：
  - 2 线：`2×S`；
  - 2 线+PE：`2×S+1×PE`；
  - 正极接地：`2×S`，备注“正极接地，PE 按接地系统设置”。
- 计算书：
  - 第 ② 步 DC 公式；
  - 第 ④ 步显示“国家标准 2 根导体表 / 厂家表”来源；
  - 第 ⑤ 步 DC 压降 `2×I×L×R`；
  - 第 ⑦ 步 DC 保护说明；
  - 增加“DC 设计提示”块。
- 来源标签：
  - 2 根导体表：`查表 B.52.2 / B.52.3`；
  - 厂家表：`厂家表` + 厂家/表名；
  - 压降限值：`预设` / `输入`；
  - DC 保护：`说明`。

## 7. 数据模型

```ts
export type DcCircuitType = 'load' | 'charge' | 'discharge' | 'rectifier' | 'bus'
export type DcWiring = 'twoWire' | 'twoWirePe' | 'positiveEarthed'
export type DcAmpacitySource = 'standard' | 'manufacturer'

export interface CableSizingInput {
  // 现有字段...
  dcCircuitType: DcCircuitType
  dcWiring: DcWiring
  dcAmpacitySource: DcAmpacitySource
  /** 当前材料+绝缘+敷设方式组合的 16 个厂家载流量值；空数组表示未填 */
  dcManufacturerAmpacity: number[]
  /** 厂家/表名，仅用于展示和计算书 */
  dcManufacturerName: string
}
```

- 2 根导体国家标准表：`AMPACITY_DC_2`，结构与现有 `AMPACITY` 一致（Cu/Al × PVC/XLPE × A1–G × 16 截面）。
- 厂家表：`dcManufacturerAmpacity` 覆盖当前组合的 16 个值；不建多厂家库。
- 计算书/可追溯：新增 `source: 'manufacturer'` 或复用 `table` + `sourceDetail: '厂家表 · 厂家名'`。

## 8. 计算书与可追溯

- 第 ③ 步：DC 下 `kh = 1.00（直流不适用）`，`ks` 仍按埋地/非埋地。
- 第 ④ 步：`I_table` 来源显示“国家标准 2 根导体表”或“厂家表 · 厂家名”。
- 第 ⑤ 步：`ΔU = 2×I×L×R`，不显示 `cosφ/X`。
- 第 ⑦ 步：DC 保护说明，不套 AC `k3`。
- 参数说明表：增加 DC 相关条目（回路类型、导线制式、载流量数据源、厂家表）。

## 9. 测试

- 2 根导体表：抽 4–6 个黄金点（Cu/PVC/C、Cu/XLPE/C、Al/XLPE/D 等），固定输入 → 固定截面/载流量。
- DC 压降：`ΔU = 2×I×L×R`，与手算一致。
- 回路类型：标签/提示切换，不改变引擎结果。
- 导线制式：`2×S` / `2×S+1×PE` 标签。
- 厂家表：覆盖 16 个值后引擎使用厂家值；空表回退国家标准表并提示。
- 计算书：DC 步骤、来源标签、无 `cosφ/X`。
- 页面：1440×900 截图；DC 模式字段、厂家表编辑、计算结果。
- 门禁：`type-check`、`lint:check`、`vitest`、`build-only`。

## 11. 验收标准

- DC 模式下只显示 DC 相关字段，不显示谐波/电机启动。
- 载流量默认使用 2 根导体国家标准表；可切换厂家表。
- 厂家表为空/无效时回退国家标准表并提示。
- 压降按 `2×I×L×R`，允许压降可 3%/5%/自定义。
- 电缆标签区分 2 线 / 2 线+PE / 正极接地。
- 计算书显示 DC 公式、数据源和保护说明。
- 不出现电池/整流器容量计算。
- 全部门禁通过。

## 13. 风险

- 2 根导体表逐格转录容易出错，必须配黄金用例和来源标注。
- 厂家 DC 表格式不统一，16 行覆盖只适合“当前组合”，不适合多厂家多工况。
- DC 保护电器选型不在本轮，结果页必须明确“仅电缆校核”。
- 直流压降限值、电缆电压等级、接地制式需按项目规范复核。
