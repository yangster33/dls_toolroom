# 工具 26 · 机房空调制冷量计算 · 显式可追溯改造计划

> 分支：`maint/tool-26-hvac-cooling`
> 日期：2026-11-10
> 状态：已实施（2026-11-11，见 §13）
> 范围：只改展示层与数据描述，不改冷负荷/机组选型计算模型

## 1. 现状

现有页面按“机房与计算方式 → 冷负荷分项 → 选型与换算”输入，右侧给结论、冷负荷分项表和校核表。

- 输入：机房类型、计算方式（详细/面积）、面积、面积指标、IT 功率、发热系数、电力损耗、围护结构、照明 W/m²、人数、人体散热 W/人、新风模式/风量/焓差、新风负荷、其他负荷、设计余量、冗余（无/N+1/2N）、机组类型、单台容量、运行台数、负荷显热比、机组显热比、修正系数、匹数基准。
- 结果：总冷负荷、设计冷负荷、所需冷量、显热/潜热、负荷显热比、面积指标、分项负荷、P/RT、机组台数、安装容量、运行容量、故障容量、负载率、显冷量。
- 校核：运行冷量、显冷量、单台负载率、设计余量、面积指标。

问题：

- 冷负荷分项只有“数值 + 备注”，没有统一公式、来源和占比；
- 没有逐步计算书，设计余量、修正系数、显热比、冗余、单台容量之间的推导链不可见；
- 校核表只有“要求 / 实际 / 结论”，没有裕度、为什么、控制标记；
- 没有来源标签，机房类型预设、标准机组容量、3.517 kW/RT、2.5 kW/P 等来源不清；
- 没有参数说明表，用户不知道哪些是规范/厂家/项目值；
- 右栏没有吸顶速览。

## 2. 目标

每个数都能回答：

1. 从哪来？（输入 / 查表 / 计算 / 常数 / 默认）
2. 怎么算？（公式、代入、表号、预设）
3. 能不能改？（直接改 / 间接改 / 不能改）
4. 校核差多少？为什么通过/不通过？由谁控制？

## 3. 复用工具 23 的四个模式

1. **计算书**：步骤可折叠，折叠显示关键值，展开显示公式、代入、符号、来源、备注。
2. **来源标签**：`输入 / 查表 / 计算 / 常数 / 默认`，符号 chip 带标签。
3. **校核明细**：每条校核可展开，显示要求式、实际式、裕度、来源符号、“为什么”、控制标记。
4. **参数说明 + 视口优先**：参数表增加“来源 / 可修改 / 依据”；右栏吸顶速览，默认折叠计算书。

## 4. 计算书步骤

### ① 冷负荷分项

详细模式：

```text
IT 设备散热 = P_IT × 发热系数
电力设备损耗 = 输入值
围护结构 + 太阳辐射 = 输入值
照明散热 = 照明 W/m² × 面积 / 1000
人体散热 = 人数 × W/人 / 1000
新风负荷 = 1.2 × 风量 × 焓差 / 3600   （或直接输入）
其他负荷 = 输入值
```

面积模式：

```text
总冷负荷 = 面积指标 W/m² × 面积 / 1000
```

- 关键值：`总冷负荷 = 38.5 kW`；
- 每个分项显示：公式、代入、kW、占比、来源；
- 符号：`P_IT`、`K_heat`、`A`、`L_light`、`N_people`、`q_people`、`L_fresh`、`Δh`、`Q_item`。

### ② 总冷负荷 / 设计冷负荷

```text
总冷负荷 = Σ 分项
设计冷负荷 = 总冷负荷 × (1 + 设计余量)
```

- 关键值：`设计冷负荷 = 44.3 kW`；
- 符号：`Q_total`、`K_margin`、`Q_design`。

### ③ 所需冷量

```text
所需冷量 = 设计冷负荷 / 修正系数
```

- 关键值：`所需冷量 = 44.3 kW`；
- 说明：修正系数用于海拔、工况、污垢等修正，来源为输入/项目。

### ④ 显热 / 潜热

```text
显热负荷 = 设计冷负荷 × 负荷显热比
潜热负荷 = 设计冷负荷 - 显热负荷
```

- 关键值：`显热 39.9 kW / 潜热 4.4 kW`；
- 符号：`SHR_load`、`Q_sensible`、`Q_latent`。

### ⑤ 机组台数 / 单台容量

```text
自动运行台数 = max(1, ceil(所需冷量 / (0.9 × 最大标准容量)))
单台容量 = nextStandardUnitKw(所需冷量 / (运行台数 × 0.9))
备用台数 = 无 ? 0 : N+1 ? 1 : 运行台数
安装台数 = 运行台数 + 备用台数
安装容量 = 安装台数 × 单台容量
运行容量 = 运行台数 × 单台容量
```

- 关键值：`2 运行 + 1 备用 × 25 kW = 75 kW`；
- 符号：`N_run`、`Q_unit`、`N_backup`、`N_install`、`Q_install`、`Q_run`；
- 来源：标准机组容量（常数表/厂家）、冗余方式（输入/规范）。

### ⑥ 显冷量校核

```text
机组显冷量 = 运行容量 × 机组显热比
要求：机组显冷量 ≥ 显热负荷
```

- 关键值：`机组显冷量 45.0 kW ≥ 39.9 kW`；
- 符号：`SHR_unit`、`Q_unit,sensible`。

### ⑦ 负载率 / 面积指标

```text
单台负载率 = 所需冷量 / 运行容量
面积指标 = 总冷负荷 × 1000 / 面积
```

- 关键值：`负载率 59.1%`、`面积指标 500 W/m²`；
- 要求：负载率 ≤ 90%，面积指标在机房类型预设范围内。

### ⑧ 匹数 / RT 换算

```text
匹数 = 所需冷量 / 匹数基准
RT = 所需冷量 / 3.517
```

- 关键值：`17.7 匹 / 12.6 RT`；
- 来源：`匹数基准`（输入/市场口径）、`3.517 kW/RT`（常数）。

## 5. 校核明细

每条校核改成可展开卡片：

| 校核 | 要求 | 实际 | 裕度 | 控制 |
|---|---|---|---|---|
| 运行冷量 | `≥ 44.3 kW` | `50.0 kW` | `+5.7 kW` | 可能 |
| 显冷量 | `≥ 39.9 kW` | `45.0 kW` | `+5.1 kW` | 可能 |
| 单台负载率 | `≤ 90%` | `88.6%` | `+1.4 pp` | 可能 |
| 设计余量 | `≥ 10%` | `15%` | `+5 pp` | 可能 |
| 面积指标 | `350–450 W/m²` | `500 W/m²` | `-50 W/m²` | 可能 |

额外增加“冷负荷分项”卡，避免分项只出现在表格里：

```text
冷负荷分项
IT 24.0 kW / 62.3%
电力损耗 3.0 kW / 7.8%
围护 4.0 kW / 10.4%
照明 2.4 kW / 6.2%
人体 1.5 kW / 3.9%
新风 2.8 kW / 7.3%
其他 0.8 kW / 2.1%
```

每条校核展开后显示：

- 要求式、实际式；
- 要求 / 实际 / 裕度；
- 符号 chips（来源标签）；
- “为什么”；
- “查看计算书第 X 步”。

控制项建议：

- 在 `HvacCoolingResult` 增加 `drivers: string[]`，记录最终由哪项约束决定（运行冷量 / 显冷量 / 负载率 / 面积指标）；
- 校核卡用 `drivers.includes(label)` 标记“控制”。

- 机房类型面积指标、发热系数、新风焓差依赖项目条件，内置预设只能作初选；

- 匹数是市场口径，不能作为设计依据，结果页要明确。
