# 电缆选型工具 · 计算显示与可追溯方案

> 分支：`maint/tool-23-cable-sizing`
> 日期：2026-11-09
> 状态：已实施（2026-11-09）
> 范围：只改展示层与数据描述，不改计算引擎；交流/直流差异不在本轮

## 1. 背景

计算书目前能给出结果，但很多数只显示“值”，不显示“从哪来”：

- 第 ③ 步写成 `kt = f(θ)`、`kg = f(敷设方式, 成束根数)`、`ks = f(ρ)`、`kh = f(h3)`，
  是占位符，不是可读的公式。
- `R`、`I_table`、`k`、`In` 直接给结果，没有表号、插值过程或选择规则。
- 用户分不清一个值是**输入**、**查表**、**计算**还是**固定常数**，也不知道能不能改。
- 例如 `ks = 1.00` 在非埋地时是“不适用”，不是默认值；`R` 由电阻率、截面、并联根数算出，不能直接改。

目标：计算书里每一个数都能回答三个问题：

1. 从哪来？（输入 / 查表 / 计算 / 常数 / 默认）
2. 怎么算的？（公式、表号、插值点、代入值）
3. 能不能改？（直接改 / 间接改 / 不能改）

## 2. 本轮范围

| 做 | 不做 |
|---|---|
| 系数查表与插值过程 | 交流/直流口径差异 |
| `R`、`I_table`、`k`、`In` 的推导 | 高级参数覆盖（ρ20、α、k、R） |
| 符号来源标签 | 厂家载流量表导入 |
| 步骤折叠 + 关键值摘要 | 计算引擎修改 |
| 参数说明表加“来源 / 可修改” | 新的选型约束 |

## 3. 系数查询透明化

### 3.1 温度修正 kt

温度修正不是公式，是**查表 + 线性插值**：

- 空气：表 B.52.14，基准 30 ℃；土壤：表 B.52.15，基准 20 ℃。
- 表点是离散的，落在两点之间时：

```text
kt = kt1 + (θ - θ1) / (θ2 - θ1) × (kt2 - kt1)
```

计算书显示三行：

```text
查表：B.52.14（XLPE，空气），基准 30 ℃
点：30 ℃ → 1.00，35 ℃ → 0.96
θ = 35 ℃，正好是表点 → kt = 0.96
```

如果 θ = 33 ℃：

```text
kt = 1.00 + (33 - 30) / (35 - 30) × (0.96 - 1.00) = 0.976
```

超出表范围时显示“按边界值取值”和对应警告。

### 3.2 成束修正 kg

- 空气：表 B.52.17，按敷设方式分行（A/B 成束、C 单层、E/F 托盘、G 梯架）。
- 埋地：表 B.52.18，按间距分列。
- 显示：表号 + 行/列 + 成束根数 + 结果。

```text
查表：B.52.18（埋地，相触）
列：6 回路 → 0.50
成束根数 = 3 回路 × 2 根 = 6 根 → kg = 0.50
```

### 3.3 土壤热阻率修正 ks

- 仅埋地：表 B.52.16，直埋行，基准 2.5 K·m/W。
- 显示：ρ 的插值点 + 结果。
- 非埋地：显示 `ks = 1.00（非埋地，不修正）`，不要只给 1.00。

```text
查表：B.52.16（直埋）
点：2.5 → 1.00，3.0 → 0.90
ρ = 3.0 → ks = 0.90
```

### 3.4 谐波修正 kh

- 表 E.52.1，按 h3 分档。
- 显示：档位 + 是否按中性线选型。

```text
查表：E.52.1
h3 = 40% → 33–45% 档，kh = 0.86，按中性线电流选型
```

## 4. 中间值透明化

### 4.1 导体电阻 R

现在只给 `R = 1.374 Ω/km`，应补：

```text
ρ90 = 0.01724 × [1 + 0.00393 × (90 - 20)] = 0.02198 Ω·mm²/m
R = 0.02198 / 16 / 1 = 1.374 mΩ/m = 1.374 Ω/km
```

显示内容：ρ20、α、θmax、S、n，以及 ρθ 和 R。

### 4.2 基准载流量 I_table

显示：材料 / 绝缘 / 敷设方式 / 截面 + 表号。

```text
查表：Cu / XLPE / C，16 mm² → 89.0 A/根
```

### 4.3 热稳定系数 k

显示查表值：

```text
查表：Cu / XLPE → k = 143
```

### 4.4 保护电器 In

- 自动：显示选择规则和标准系列。

```text
自动匹配：取不小于 max(Ib, IN) = 57.2 A 的最小标准壳架 → 63 A
```

- 手动：显示“输入值”。
- 熔断器：显示 k3 规则（In < 16 A → 1.31；In ≥ 16 A → 1.10）。

### 4.5 线路电抗 X

- 显示“输入值”或“默认值 0.08 Ω/km”。
- 用户修改后显示“输入值”。

## 5. 来源标签

每个符号增加一个来源标签：

| 标签 | 含义 | 交互 |
|---|---|---|
| 输入 | 左侧表单填写 | 点一下高亮对应输入框 |
| 查表 | 来自标准表 | 展开显示表号、行列、插值 |
| 计算 | 由其他值算出 | 跳到计算它的步骤 |
| 常数 | 标准固定值 | 显示数值和依据 |
| 默认 | 可改但当前是默认值 | 提示默认值和修改位置 |

示例：

| 符号 | 来源 | 可修改 |
|---|---|---|
| θ | 输入 | 是 |
| kt | 查表 B.52.14 | 间接（改 θ） |
| ρ | 输入（仅埋地） | 是 |
| ks | 查表 B.52.16（仅埋地） | 间接（改 ρ） |
| R | 计算（ρ20、α、θmax、S、n） | 间接；高级参数可覆盖（本轮不做） |
| k | 常数 | 否（本轮不做覆盖） |
| I_table | 查表 | 否（内置表） |

参数说明表增加两列：**来源 / 可修改**。

## 6. 步骤折叠 + 关键值

外层“计算书”仍默认折叠；展开后，7 个步骤各自是一个 `<details>`，默认全部折叠。

折叠状态下每行显示：步骤号 + 标题 + 最关键的值 + 判定：

```text
① 计算负荷    Pjs = 24.00 kW
② 计算电流    Ib = 47.67 A
③ 修正系数    kt / kg / ks / kh = 0.96 / 1.00 / 1.00 / 1.00
④ 载流量      Iz = 85.4 A          通过
⑤ 电压降      ΔU = 2.10 %           通过
⑥ 短路热稳定  Smin = 13.27 mm²      通过
⑦ 保护配合    通过
```

展开某一步，显示公式、代入、符号 chips、备注。由 `drivers` 控制的步骤加“控制”标记，可默认展开。

## 7. 数据模型

```ts
export type SymbolSource = 'input' | 'table' | 'calc' | 'constant' | 'default'

export interface CalcSymbol {
  symbol: string
  name: string
  value: string
  unit?: string
  inputSymbol?: string
  source: SymbolSource
  sourceDetail?: string
}

export interface CalcStep {
  key: string
  index: number
  title: string
  /** 折叠时显示的关键值，如 "Pjs = 24.00 kW" */
  keyValue: string
  formula: string
  substitution: string
  result: string
  symbols: CalcSymbol[]
  pass?: boolean
  note?: string
}
```

新增查询描述函数（放 `correctionFactors.ts` 或新 `traceability.ts`）：

- `describeTemperatureFactor(insulation, medium, temp)` → 表号、基准温度、插值点、结果、是否截断。
- `describeGroupingFactor(method, count, spacing)` → 表号、行/列、结果。
- `describeSoilFactor(rho, buried)` → 表号、插值点、结果、是否不适用。
- `describeHarmonicFactor(h3)` → 档位、是否按中性线。
- `describeResistance(input, result)` → ρ20、α、θmax、ρθ、R。
- `describeThermalK(material, insulation)` → k 与表号。
- `describeBreaker(input, result)` → 自动/手动、规则、标准系列。

## 9. 测试

- 查询描述：
  - kt 正好落在表点、落在两点之间、超出范围；
  - kg 空气 / 埋地、不同根数；
  - ks 埋地 / 非埋地；
  - kh 四个档位。
- 步骤生成：
  - 每步 `keyValue` 非空；
  - 每个符号 `source` 非空；
  - 第 ⑤ 步包含 ρθ 和 R 的推导；
  - 不再出现 `f(...)` 占位符。
- 页面：
  - 1440×900 截图：计算书展开后 7 行折叠摘要；
  - 展开一步后显示完整推导；
  - 参数说明表含“来源 / 可修改”列。
- 门禁：`type-check`、`lint:check`、`vitest`、`build-only`。

## 10. 验收标准

- 计算书中不再出现 `f(...)`；每个系数都有表号、插值点/行列、结果。
- `R` 有 ρθ 公式和常数；`I_table` 有表号；`k` 有查表值；`In` 有选择规则。
- 每个符号有来源标签；参数说明表有“来源 / 可修改”。
- 计算书展开后默认 7 行摘要，点开某步才显示完整推导。
- 页面高度和 16:9 首屏不劣于当前版本。
- 全部门禁通过。

## 11. 实施顺序

1. `refactor(cable): 修正系数查询返回表号与插值明细`
2. `feat(cable): 计算书步骤折叠与关键值摘要`
3. `feat(cable): 符号来源标签与参数说明来源列`

## 12. 不做

- 交流/直流口径差异（先按现有 AC 表和保护逻辑展示）。
- 高级参数覆盖（ρ20、α、k、R）。
- 厂家载流量表导入。
- 计算引擎修改。

## 13. 已确认的实现选择

- 来源标签用文字（输入 / 查表 / 计算 / 常数 / 默认）+ 颜色区分。
- 温度表只显示相邻两点（bracket points），不显示完整表。
- `X = 0.08` 标“默认”，用户改动后标“输入”。
- 不单独加图例；标签文字自解释，参数说明表提供完整说明。
