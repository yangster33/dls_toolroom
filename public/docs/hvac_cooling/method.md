# 法

## 1. 输入与边界

- **机房类型**：只影响面积经验指标和显热比默认值，不改变详细法公式。
- **面积**：用于照明、新风和面积指标校核，不直接等于冷负荷。
- **设备功率**：通信 / IT 设备的输入功率，不是 UPS 容量，也不是机房总用电。
- **发热系数**：一般通信机房可取 1.00；UPS、整流器等电力设备按效率损失另算。
- **围护结构 + 太阳辐射**：按 GB 50736 / GB 50019 逐时计算，方案阶段可估算。
- **新风**：可按风量和焓差估算，也可直接输入冷负荷。
- **设计余量**：无备份时按 GB 50174-2017 7.5.3 留 15%~20%。
- **综合修正系数 K**：高海拔、高温、长管路等按厂家样本修正；K < 1 时所需制冷量放大。

## 2. 详细分项法

```text
Q总 = Q设备 + Q电力损耗 + Q围护 + Q照明 + Q人体 + Q新风 + Q其他
```

- 设备：`Q设备 = P设备 × 发热系数`
- 照明：`Q照明 = 照明功率密度 × 面积 / 1000`
- 人体：`Q人体 = 人数 × 每人散热量 / 1000`
- 新风：`Q新风 = 1.2 × 风量(m³/h) × 焓差(kJ/kg) / 3600`
- 电力损耗：`Q损耗 = P × (1 − η)`，或按设备实际损耗统计

单位统一为 kW。

## 3. 面积指标法

```text
Q总 = qA × A / 1000
```

`qA` 是经验指标，常用范围：

| 机房类型 | 经验指标 W/m² |
|---|---|
| 通信交换机房 / 基站 | 350~450 |
| 数据中心 / IDC | 600~1200 |
| 金融机房 | 500~600 |
| 计算机房 / 控制中心 | 350~450 |
| 辅助机房 / 值班室 | 150~250 |

这些数值来自设计手册和工程经验，**不是 GB 强制指标**。施工图阶段必须逐项计算。

## 4. 设计冷负荷与设备所需制冷量

```text
Q设计 = Q总 × (1 + 设计余量)
Q需   = Q设计 / K
```

- `K` 为综合修正系数，默认 1.00。
- 无备份时设计余量应 ≥15%；有 N+1 / 2N 时可放宽，但仍建议留 10% 左右。

## 5. 显冷量校核

通信机房热负荷以显热为主，不能只看总制冷量：

```text
Q显 = Q设计 × 机房显热比
Q设备显冷 = 运行冷量 × 空调显热比
```

应满足 `Q设备显冷 ≥ Q显`。舒适性空调的显热比通常只有 0.70~0.80，容易“总冷量够、显冷量不够”。

## 6. 选型与冗余

- **无备份**：运行冷量 ≥ Q需，单台负载率建议 ≤90%。
- **N+1**：N 台运行 + 1 台备用；故障时备用自动投入，仍满足 Q需。
- **2N**：N 台运行 + N 台备用；单侧故障时另一侧仍满足 Q需。

工具会自动推荐单台容量和台数，也可以手动指定“运行台数 N”和“单台容量”。

## 7. 匹数换算

```text
P ≈ Q需 / 2.5        （市场常用口径）
P ≈ Q需 / 2.324      （老口径，1P≈2000 kcal/h）
```

“匹”不是我国法定计量单位，1P 实际对应 2.2~2.6 kW 的区间。换算结果只用于市场沟通，设计文件应写 kW。

冷水机组还可按冷吨估算：`RT ≈ Q需 / 3.517`（1 RT = 3.517 kW）。
