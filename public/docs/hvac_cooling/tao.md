# 道

机房空调选型，最容易混淆的是三个东西：**冷负荷、设备制冷量、市场匹数**。

冷负荷是机房在单位时间内需要搬走的热量，单位是 kW；设备制冷量是空调在名义工况下能搬走的热量，单位也是 kW；匹数只是市场对制冷量的俗称，不是法定计量单位。三者不能互相替代。

标准把边界划得很清楚。GB 50174-2017 只说冷负荷由哪些部分组成、设备散热按实际用电量算、无备份时留 15%~20% 余量；YD/T 5003 补充通信机房的设备发热、人体轻作业和新风量；真正逐时计算的方法在 GB 50736 和 GB 50019。没有任何一本国标规定“算出来等于几 P”。

所以这个工具的顺序是：**先算 kW，再选 kW，最后才把 kW 翻译成 P 供沟通**。反过来用“几匹”倒推机房能带多少设备，往往会在显热比、冗余和工况修正上出错。

标准不是装饰，边界比数字重要。把“方案初选”和“施工图计算”分开，把“标准值”和“经验值”分开，工具才不会制造虚假的精确感。
