# 器

## 工具简介

按设备功率、围护结构、人员、照明与新风逐项计算通信机房冷负荷，换算 kW 与市场匹数，并给出 N+1 / 2N 选型建议。

## 使用方法

1. 选择机房类型，填写机房面积。
2. 选择计算方式：详细分项法或面积指标法。
3. 详细法填写设备功率、发热系数、电力损耗、围护结构、照明、人员和新风；面积法只填面积指标。
4. 设置设计余量、冗余方式、空调类型、运行台数、单台容量、显热比和修正系数。
5. 右侧查看设备所需制冷量、市场匹数、冷负荷分项、选型建议和校核明细。
6. 点击“复制计算书”复制文字版结果。

## 输出内容

- 计算冷负荷、设计冷负荷、设备所需制冷量（kW）。
- 市场俗称匹数（P）和冷水机组冷吨（RT）。
- 冷负荷分项及占比。
- 推荐配置：运行台数、备用台数、单台容量、总装机。
- 单台负载率、故障后可用冷量、显冷量。
- 冷量、显冷量、负载率、设计余量、面积指标等校核项。
- 可复制的文字计算书。

## 注意事项

1. 标准只规定冷负荷组成和计算方法，不规定“几匹”；“匹”是市场俗称，不是法定计量单位。
2. 面积指标是经验值，只用于方案估算；施工图应按 GB 50736 / GB 50019 逐项计算。
3. 通信机房应以显冷量校核，不能只看总制冷量；舒适性空调的显热比通常偏低。
4. 无备份时按 GB 50174-2017 7.5.3 留 15%~20% 余量。
5. 高海拔、高温、长管路应按厂家样本修正，工具中的综合修正系数只是简化入口。
6. 本工具用于方案初选，正式设计应由暖通工程师按现行标准和厂家资料复核。
