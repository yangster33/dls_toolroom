# 法

## 1. 输入与边界

- 直流电压：-48V、-24V、240V、336V；-48V 最常用。
- 近期负荷：可直接输入电流 A，也可输入功率 kW 后按 `I = P×1000 / U` 换算。
- 蓄电池容量 Q：来自蓄电池计算工具或厂家配置；均充电流按 `I_c = Q × k` 估算。
- 远期/近期负荷比：用于校核满架容量和柜体 U 位预留。
- 模块：额定电流、降额系数、冗余方式（N / N+1 / N+2）、单模块 U 数。
- 柜体：拟用高×宽×深、单柜最大模块数、监控/配电/备用 U 数。

## 2. 电流计算

```text
近期负荷电流     I_L = P×1000 / U        （按功率输入时）
均充电流         I_c = Q × k             （k 常取 0.1，即 0.1C10）
近期设计电流     I_d = I_L + I_c
远期电流         I_f = I_d × 增长系数
模块有效电流     I_m = I_额定 × 降额系数
```

## 3. 模块数量（GB 51194-2016 5.3.1 / 5.3.2）

```text
主用模块数       N = ⌈ I_d / I_m ⌉
配置模块数       N + 备用数（N+1 为 1，N+2 为 2）
满架模块数       ⌈ I_f / I_m ⌉ + 备用数
```

- 5.3.1：整流器、变换器容量按近期负荷配置。
- 5.3.2：组合电源整流模块数可按近期负荷配置，但满架容量应考虑远期负荷发展。
- 模块降额系数用于高温、高海拔、通风不良等场景；正式设计按厂家降额曲线。

## 4. 柜体 U 位

```text
占用 U = 满架模块数 × 单模块 U + 监控/配电/备用 U
柜数   = max( ⌈占用 U / 单柜可用 U⌉, ⌈模块槽位 / 单柜最大模块数⌉ )
```

常用 19in 柜高与可用 U：

| 柜高 | 可用 U（参考） |
|---|---|
| 1600 mm | 32U |
| 2000 mm | 42U |
| 2200 mm | 46U |
| 2600 mm | 54U |

不同厂家横梁、走线槽和配电单元会占用不同空间，可用 U 以厂家资料为准。

## 5. 断路器与交流进线

```text
直流主断路器 ≥ I_d × 1.25，向上取标准壳架
直流输出功率 P_dc = I_d × U / 1000
交流输入功率 P_ac = P_dc / η
三相交流电流 I_ac = P_ac×1000 / (√3 × 380 × PF)
单相交流电流 I_ac = P_ac×1000 / (220 × PF)
交流断路器 ≥ I_ac × 1.25，向上取标准壳架
```

断路器壳架只是初选，最终要校验分断能力、上下级选择性和直流拉弧。

## 6. 柜体尺寸

GB 51194 不规定柜体宽×深×高。工具给出的推荐尺寸按以下顺序确定：

1. 模块数量、模块 U 数和备用 U 位决定柜高；
2. 单柜最大模块数决定是否需要多柜；
3. 额定电流大于 600A 或模块槽位大于 16 个时，宽度建议 800mm，否则 600mm；
4. 额定电流大于 1000A 时，深度建议 800mm，否则 600mm；
5. 最终按 GB/T 3047.1-1995 的 20mm 进制系列、GB/T 19520.1-2007 的 19in 结构和厂家型谱确认。

## 7. 校核项

- 整流容量：降额后配置容量 ≥ 近期设计电流。
- 冗余：配置模块数 − 主用模块数 ≥ 设定备用数。
- 满架容量：满架模块容量 ≥ 远期电流。
- 模块槽位：槽位数 ≤ 单柜最大模块数 × 柜数。
- U 位：占用 U ≤ 可用 U × 柜数。
- 直流主断路器、交流输入断路器：标准壳架 ≥ 计算电流。
