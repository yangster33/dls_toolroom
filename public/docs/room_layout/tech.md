# 机房平面图生成 · 术

## 流水线

```text
参数 → 分区（电源/电池/空调靠墙）→ 横向机柜列 → 走线架
     → 每台机柜束路由 → 评估（线缆 + 走线架 - 面积利用率）
     → 多起点模拟退火 → Top 3
```

## 规则（默认）

- 冷通道 ≥ 1200 mm；
- 热通道 ≥ 1000 mm；
- 搬运通道 ≥ 1500 mm；
- 电源柜正面 ≥ 1500 mm；
- 电池架通道 ≥ 1000 mm；
- 空调正面 ≥ 1500 mm；
- 走线架宽 400 mm，分支 300 mm，填充率 ≤ 45%。

规则集中在 `rules.ts`，页面可继续扩展为可配置项。

## 可复现

同一 `seed` + 参数 → 同一套设备坐标与标注；方案按 `seed` 重新生成即可复现。

## 线缆

首版按曼哈顿路径计算「机柜 → 分支走线架 → 主干 → 馈线窗」的束长，用于方案比较，不代替真实线缆表。
