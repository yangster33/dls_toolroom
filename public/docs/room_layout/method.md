# 机房平面图生成 · 法

## 先定边界

- 房间：矩形 / L 形；
- 设备：机柜、电源柜、电池架、空调；
- 走线架：1 条主干 + 每列 1 条分支；
- 线缆：AC / DC / 光纤 / 信号四类，按束；
- 优化：加权单目标，输出 Top 3；
- 导出：SVG / PNG / JSON。

## 推荐流程

1. 输入房间真实尺寸（mm）与机柜数量；
2. 生成 Top 3，先看「可行/需复核」与警告；
3. 对比线缆总长、走线架总长、面积利用率；
4. 选一个方案导出 SVG，交给设计/施工方复核；
5. 需要调整时改 seed 或设备数量重新生成。

## 不要用它做什么

- 不代替施工图设计；
- 不做结构承重、消防、气流场计算；
- 不输出 DWG；需要 DWG 请导出 DXF/在 CAD 中处理（二期）。
