# 图框图签生成器

A0~A5 图幅、GB 风格图框、交互式图签设计，支持 JSON Schema、SVG 与 DXF 导出。

## 能做什么

- 选择 A0 / A1 / A2 / A3 / A4 / A5 图幅，横版 / 竖版；
- 设置装订边、上 / 下 / 左 / 右边距、图框线宽；
- 打开 / 关闭对中符号、分区标记；
- 按图幅推荐标题 / 正文 / 注释 / 标签字高，也可手动覆盖；
- 在画布中拖动、缩放、复制、删除图签单元格；
- 绑定工程名称、图名、图号、比例、日期、设计、审核、单位等字段；
- 自定义字段：在专业模式里添加“建设单位”“校对人”等字段，并绑定到任意单元格；
- 字体：切换微软雅黑 / 宋体 / 黑体 / Noto Sans SC / 思源黑体，或输入自定义 font-family；
- 字高：按文字样式统一调整标题 / 正文 / 注释 / 标签的字号和加粗，也可对单个单元格覆盖字号和粗细；
- 专注编辑：隐藏左右面板，把表格编辑 / 图纸预览放大到整屏宽度；
- 导出 JSON（含字段值）、JSON Schema、SVG、DXF；
- 浏览器本地完成，不上传图纸。

## 两种模式

页面右上角可以在两种模式之间切换，当前文档会保留：

| 模式 | 适合谁 | 暴露的功能 |
|---|---|---|
| 新手引导（默认） | 第一次使用 | 4 步向导：图幅 → 图签 → 内容 → 导出 |
| 专业模式 | 需要改结构 / 精调 | 三栏工作台：边距、字高、显示图层、表格增删行列、合并拆分、校验 |

首次打开会自动进入新手引导并显示帮助提示；切换过模式后会记住上次选择。

## 新手引导（推荐首次使用）

1. **图幅**：点选 A0~A5 卡片，选择横版 / 竖版；边距和字高自动按图幅推荐；
2. **图签**：从国标风格 / 简洁图签 / 极简图签中选一张，卡片带图签缩略图；
3. **内容**：
   - 中间是放大的图签预览；
   - 点击任意单元格，右侧出现编辑表单；
   - “绑定字段”下拉可以直接把单元格绑定到工程名称、图名、图号、比例、日期、设计、审核、单位等字段；
   - 绑定后填写“字段值”，预览实时更新；
   - 不绑定字段时，直接编辑“文字内容”；
   - 右侧“常用字段”可以快速填写全部常用信息，也可以点“填入示例数据”；
4. **导出**：预览完整图纸，选择 SVG / PNG / DXF / JSON；更多格式里还有 JSON Schema 和导入 JSON。

底部“上一步 / 下一步”移动；第 4 步完成后可点“完成，进入专业模式”继续调整结构。

## 专业模式使用步骤

1. 左侧选择图幅和横竖版；
2. 调整边距、图框、字体 / 字高；
3. 选择“GB 风格 / 简洁 / 极简”图签模板；
   - GB 风格包含更改区、签字区、材料/比例区等标准分区，因此会有跨行/跨列单元格；
   - 需要更少合并时选“简洁”或“极简”。
4. 在画布中点击单元格，右侧修改标签、字段、坐标、宽高、对齐、字号覆盖、粗细；
5. 在“字段值”里填写工程信息；需要新字段时在“自定义字段”里添加；
6. 看“校验”面板，处理文字溢出、字高过低、图签超框等警告；
7. 导出 JSON / Schema / SVG / DXF。

编辑区太窄时，点“表格编辑 / 图纸预览”右上角的“专注编辑”，会隐藏左右面板，把编辑区扩展到整屏；再点“退出专注”恢复。

## 自定义字段

专业模式右侧“字段值”面板底部有“自定义字段”：

1. 填字段名称，例如“建设单位”；
2. 填字段键，例如 `clientName`（字母 / 数字 / 下划线，不能以数字开头）；
3. 点“添加”；
4. 新字段会出现在：
   - “字段值”列表，可直接填写；
   - 单元格“绑定字段”下拉，可绑定到任意单元格；
   - 导出 JSON 的 `customFields` 和 `values`。
5. 删除自定义字段时，会同时清除字段值，并解绑使用该字段的单元格。

## 字体与字高

- 左侧“字体 / 字高”：
  - 字体下拉提供微软雅黑 / 苹方、宋体、黑体、Noto Sans SC、思源黑体；选“自定义…”可输入任意 CSS `font-family`；
  - 标题 / 正文 / 注释 / 标签分别设置字号和是否加粗；
  - “吸附”把字号对齐到 GB/T 14691 标准系列；
  - “按图幅推荐”恢复该图幅的推荐字高。
- 右侧“单元格属性”：
  - “文字样式”选择 title / body / note / label；
  - “字号覆盖”单独设置该单元格字号，留空则跟随样式；
  - “粗细”选择跟随样式 / 加粗 / 常规。

## 交互提示

- 点击单元格选中；
- 拖动单元格移动；
- 拖动右下角手柄缩放；
- 方向键微调 1mm，Shift + 方向键 5mm；
- Ctrl/Cmd + Z 撤销，Ctrl/Cmd + Shift + Z 或 Ctrl/Cmd + Y 重做；
- “聚焦图签”会放大并滚动到右下角图签区域。

## 元素提示（Tips）与显示开关

- 预览图中把鼠标停在图框线、对中符号、分区编号、单元格、标签、字段值上，会显示：
  - 名称（如“对中符号”“图框线”“字段值”）；
  - 标准来源（GB/T 14689-2008、GB/T 10609.1-2008）；
  - 当前值（线宽、长度、字高、文本等）；
  - “显示此类”复选框。
- 左侧“显示”面板提供元素级开关：
  - 图框：纸张边界、图框线、装订边参考区、对中符号、分区标记、分区编号；
  - 图签：图签外框、单元格边框、标签文字、字段值文字；
  - 辅助：编辑网格、鼠标提示。
- 显示状态单独保存，不写入 `SheetDocument`，不会污染撤销历史和导出 JSON；
- “导出 SVG / DXF”会按当前显示状态过滤隐藏元素。

## Excel 式图签编辑

默认打开“表格编辑”页：

- 像 Excel 一样按行/列查看图签；
- 行号、列标（A/B/C…）显示在边缘；
- 工具栏支持：
  - 上方插入行 / 下方插入行 / 删除行；
  - 左侧插入列 / 右侧插入列 / 删除列；
  - 合并 / 拆分；
  - 等宽列 / 等高行 / 内容自适应 / 归一化；
  - 拖动列标右侧手柄改列宽，拖动行号下方手柄改行高；
- 多选：Shift / Ctrl / Cmd + 点击，或按住鼠标拖动选择多个单元格；
- 合并按钮只有在选中多个单元格时可用；选中单个合并单元格时“拆分”可用；
- 表格聚焦后可用方向键移动选中单元格；
- 插入/删除行列后自动归一化，保持图签总尺寸；
- 插入行列时会在新行/新列自动创建“新单元格”；如果跨过合并单元格，会先拆分并提示；
- 空白网格双击可添加单元格；
- 双击单元格直接编辑内容：有绑定字段时改字段值，否则改标签/静态文本；Enter 提交，Esc 取消；
- 选中单元格后直接输入字符也会进入编辑（Excel 习惯）；
- 右侧属性面板继续用于文字样式、对齐、边框等高级设置；
- “图纸预览”页用于最终视觉确认，网格模式下预览为只读，避免误拖。

> 网格模式使用“行列轨道”模型：行高、列宽是独立轨道，单元格用 `row/col/rowSpan/colSpan` 定位。这样插入/删除行列时，单元格会自动平移和扩展，不需要手动改坐标。

## 导出说明

| 格式 | 用途 |
|---|---|
| JSON | 源数据，含模板 + 字段值，可再次导入/校验 |
| JSON Schema | 给外部工具校验 JSON 结构 |
| SVG | 矢量图，可直接打印或进 Illustrator/Inkscape |
| DXF | CAD 交换，R2007+ ASCII / UTF-8，AutoCAD/LibreCAD/TrueView 可打开 |

DWG 原生导出不在纯浏览器能力范围内；建议导出 DXF 后在 CAD 中“另存为 DWG”。

DXF 使用 CAD 的 Y 轴向上坐标系，导出时会自动翻转 SVG 的 Y 轴，因此图签位置、分区编号和预览图一致（图签在右下角，分区编号在图框外侧）。

CAD 的 `TEXT` 字高按大写字母高度解释，和浏览器 `font-size` 不完全等价。导出面板提供：

- “按预览校准 DXF 字高”（默认开启）：中文按 1.12 倍、英文/数字按 0.8 倍校准；
- “字高倍率”：在校准基础上再整体微调，默认 1.00；
- 关闭校准后，DXF 使用与模板相同的名义字高（例如正文 5mm）。

如果 CAD 打开后仍看到上下颠倒，请检查是否用了旧版本导出的文件。
