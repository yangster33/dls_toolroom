# 法

## 1. 输入与边界

- 负载：UPS 额定容量 × 负载率 × 功率因数，或直接输入有功功率 kW。
- 备电时长 T：分钟换算为小时。
- 环境温度 t：取电池室最不利的**最低**温度做容量修正；最高温度用于寿命提示。
- 直流母线电压 U：由电池组标称电压和单体规格确定串联数。

## 2. 铅酸：安时法（GB 51194-2016）

```text
Q ≥ K · I · T / ( η_ah · Kt )      Kt = 1 + α(t − 25)
```

- K：安全系数（设计余量），取 1.25。
- I：放电电流，`I = P×1000 / (U×η_inv×η_line)`。
- T：放电小时数。
- η_ah：放电容量系数，按放电小时率和终止电压查表；工具内置常用典型值，可手动修改，计算书会同时给出查表建议值。
- α：温度系数，放电小时率 ≥10h 取 0.006，1~10h 取 0.008，<1h 取 0.01。
- t：最低环境温度，℃；Kt 下限按 0.5 取值。

选型时按标准 Ah 向上取整；单只容量超过 1000 Ah 时拆成多组并联。

## 3. 铅酸：恒功率校核

UPS 是恒功率负载，短时放电更推荐查厂家恒功率表：

```text
P_cell = P×1000×K / (N_cells×η_inv×η_line)   [W/单体]
```

按备电时长和终止电压查厂家“W/单体”表，厂家值应不小于 `P_cell`。工具中填入厂家 W/单体即可自动校核。

## 4. 锂电：能量法

```text
E = P×T / (η_inv×η_line)
E_req = E×K / (DOD×SOH×KT)
Q = E_req×1000 / U
```

- DOD：放电深度，常取 0.8~0.9。
- SOH：寿命末期健康度，常取 0.8。
- KT：温度降额系数，25 ℃ 取 1.0，低温按厂家曲线取大。
- 倍率校核：`C = I / Q`，应不超过电芯/模组允许的最大放电倍率。

锂电不能套用铅酸的 α 公式；低温容量、充电窗口、热失控和消防要求都要单独校核。

## 5. 校核项

- 容量：配置值 ≥ 计算需求。
- 并联组数：铅酸按 GB 51194 建议不超过 4 组。
- 恒功率：厂家 W/单体 ≥ 需求值。
- 倍率：锂电 C-rate ≤ 允许值。
- 温度：铅酸关注低温容量与高温寿命；锂电关注低温充电禁止和高温老化。

## 6. 显示与可追溯

- 计算书：铅酸 8 步（负荷 → 放电电流 → 串联与终止电压 → 容量系数与温度 → 所需容量 → 并联与标准容量 → 恒功率 → 备电时间与倍率），锂电 6 步（负荷 → 放电电流 → 能量降额 → 所需容量与倍率下限 → 标准容量与能量 → 备电时间与倍率）。
- 每步显示公式、代入、结果与符号 chip，chip 标注来源：输入 / 查表 / 计算 / 常数 / 默认，并带表号、规则或插值区间。
- 终止电压的单体值限幅 1.5~1.9 V，超出范围时按边界计算并在计算书写明。
- 容量系数是输入项；计算书按备电时长给出典型表建议值，输入偏离建议值超过 0.02 时提示方向（偏低说明结果偏保守，偏高需厂家曲线复核）。
- 控制项：铅酸恒为「安时容量」，锂电取「能量容量」与「放电倍率」中真正决定配置容量的一项，校核卡与结果条同步标注。
- 校核明细的「为什么」说明该项是否控制最终容量；「查看计算书」可跳到对应步骤。

## 7. 简易模式假定

简易模式只保留核心输入，其余按下列假定参与计算（页面「简易模式假定」卡逐条显示）：

| 参数 | 取值 | 说明 |
|---|---|---|
| cosφ / η / η线 | 0.9 / 0.95 / 0.99 | UPS 与线路典型值 |
| 最低环境温度 | 30 ℃ | 偏保守；电池室更冷时请切专业 |
| 设计余量 K | 1.25（铅酸）/ 1.20（锂电） | 标准常用值 |
| 单体规格 / 终止电压 | 12 V / 1.75 V 单体 | 电池块 |
| UPS 最低直流输入 | 0.85 × 标称电压 | 粗校核；1.75 V 单体折合 0.875，留余量 |
| 放电容量系数 | 按备电时长查表 | 计算书标「查表」，不手填 |
| 厂家 W/单体 | 不校核 | 需恒功率复核时切专业 |
| 最大并联组数 | 4 组 | GB 51194 建议值 |
| DOD / SOH / KT / C_max | 0.9 / 0.8 / 1.0 / 1.0 C | 锂电常规值 |

简易模式不改变引擎公式与限幅；切回专业模式时这些值作为普通输入保留，可继续手改。
