# 器

## 工具简介

按负载功率、备电时长、环境温度和电池类型，估算机房 UPS 铅酸 / 锂电蓄电池容量，并给出串并联配置和校核结果。

## 使用方法

1. 选择电池类型：铅酸或锂电。
2. 选择负荷输入方式：按 UPS 容量或按负载功率。
3. 输入备电时长、最低环境温度、UPS 效率和线路效率。
4. 输入直流母线电压和设计余量。
5. 铅酸补充单体规格、终止电压、放电容量系数、厂家 W/单体和最大并联组数。
6. 锂电补充 DOD、SOH、温度降额和最大放电倍率。
7. 右侧查看推荐容量、串并联、校核明细和计算过程。

## 输出内容

- 推荐总容量 Ah（锂电同时显示 kWh）。
- 串联单元数、2V 单体数、并联组数。
- 放电电流、所需容量、恒功率 W/单体或 C-rate。
- 预估备电时长。
- 容量、并联、恒功率、倍率、温度等校核项。
- 可复制的文字计算书。

## 注意事项

1. 铅酸结果按 GB 51194-2016 安时法初选，短时备电必须用厂家恒功率表复核。
2. GB 50174-2017 的 15 min / 7 min 是“柴油发电机作为后备电源时”的最少备用时间，不是容量算法。
3. 温度输入应取电池室最低环境温度；高温用于寿命校核，不用于放大容量。
4. 锂电不能套用铅酸 α 公式；DOD、SOH、KT 和倍率应以厂家数据为准。
5. 多组并联需同规格、同长度、同路径，并校验均流。
6. 本工具用于方案初选，正式设计应由注册电气工程师按现行标准和厂家资料复核。
