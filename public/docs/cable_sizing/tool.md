# 工具说明

## 用途

按负荷、线路长度、导体材料、绝缘材料、敷设方式、环境温度、并列回路、允许电压降、短路电流和保护动作时间，计算低压 0.6/1 kV 电缆/导线的推荐截面，并给出载流量、电压降、短路热稳定、机械强度和保护配合的校核明细。

## 使用步骤

1. 选择系统类型，填写标称电压。
2. 选择按功率或按电流输入，填写负荷参数。
3. 填写功率因数、效率；按功率输入时再填写需要系数。三相回路可填写 3 次谐波含量（无谐波填 0）。
4. 选择导体材料、绝缘材料和敷设方式。
5. 填写线路长度、环境温度、并列回路数；大电流时可增加每相并联电缆数。
6. 直埋敷设时填写电缆间距和土壤热阻率；切换敷设方式后环境温度会自动在空气 / 土壤默认值之间切换。
7. 填写允许电压降、短路电流、保护动作时间和断路器额定电流（0 表示自动匹配），并选择保护电器类型。
8. 动力负荷可勾选“电机启动校核”，填写启动电流倍数和允许启动压降。
9. 查看右侧推荐方案和校核明细；需要时点击“复制计算书”。

## 结果解读

- **推荐截面**：每相导体的标准截面；并联时还会显示每相根数。
- **推荐规格**：按系统类型给出示例芯数组合，如 `YJV-0.6/1kV 4×185+1×95`。
- **控制项**：最终截面由哪一项约束控制，可能是载流量、电压降、短路热稳定、机械强度、保护配合或谐波。
- **校核明细**：逐项列出要求值、实际值和结论；勾选电机启动校核时会多一行启动压降。
- **结果速览**：右栏顶部固定一行推荐截面、PASS/REVIEW 和控制项；滚动时保持可见，可点“跳到结论”。
- **计算书**：右栏顶部可展开的 7 步推导（负荷 → 电流 → 修正 → 载流量 → 压降 → 热稳定 → 保护），默认折叠；展开后展示公式、符号、代入值和结果。
- **结论 / 校核 / 依据**：结论卡在计算书之后，随后是警告、五项校核明细和数据依据；页面下方另附参数说明表。
- **符号联动**：悬停或聚焦公式中的符号，左侧对应输入框会高亮。
- **载流量裕度 / 热稳定耐受**：分别表示校正载流量相对选型电流的裕度，以及所选截面在保护动作时间内的短路耐受电流。

## 注意事项

- 本工具面向方案初选，不替代施工图设计和注册电气工程师复核。
- 内置载流量表为工程常用值，正式设计应以现行标准原文表格和电缆厂家数据为准。
- 单相、直流回路按 3 根负载导体表取值，结果偏保守。
- 并联电缆已计入成束根数；多根并联时，应保证同规格、同长度、同敷设路径，并校验均流。
- 熔断器与断路器的过载保护条件不同：熔断器按 `In ≤ Iz / k3` 校核，不能直接套用 `In ≤ Iz`。
- 三次谐波大于 33% 时按中性线电流选型；谐波频谱复杂时（非纯 3 次谐波）应补充专项计算。
- 谐波、不平衡负荷、中性线电流、PE 导体截面、上下级保护选择性等未在本工具中全部展开。
- 环境温度、土壤热阻率、并列回路与实际敷设条件差异较大时，应补充专项计算。
