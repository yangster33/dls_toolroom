# 电缆选型之道

## 先定边界，再谈截面

低压电缆选型不是“查一张载流量表”就结束。一个可用的截面，至少要同时回答五个问题：

1. 正常运行时，导体会不会过热？
2. 线路末端电压能不能满足设备要求？
3. 短路时，导体和绝缘能不能扛住热效应？
4. 固定敷设的导体，截面是否满足机械强度？
5. 上级保护电器能不能在故障时可靠动作，又不误伤正常运行？

这五件事对应五类约束。工程上的做法不是逐项“差不多”，而是分别求出满足约束的最小截面，再取其中的最大值。

## 取最大，不取平均

载流量、电压降、热稳定、机械强度、保护配合，任何一项不满足，方案就不成立。因此本工具采用“多约束校核、取最大标准截面”的策略：

- 载流量决定“会不会热”；
- 电压降决定“末端能不能用”；
- 短路热稳定决定“故障时安不安全”；
- 机械强度决定“能不能施工、耐不耐久”；
- 保护配合决定“故障时跳不跳、正常时误不误跳”。

最终截面由最苛刻的那一项控制。结果页会直接标出“由哪一项控制”，方便回头优化线路长度、并联根数或保护整定。

## 并联不是简单相加

两根同截面电缆并联，载流量并不是简单翻倍。并联电缆彼此贴邻，会相互加热，成束系数要按“并列回路数 × 每相并联根数”一起查。工程上常见的情况是：计算电流不大，但为了施工或备用增加并联根数，结果成束根数翻倍、系数下降，截面并没有想象中那么省。

并联还有三个前提：同规格、同长度、同敷设路径。否则电流分配不均，先过热的那根先出问题。

## 熔断器和断路器不是一回事

断路器的 `I2` 通常小于 `1.45 In`，所以 `In ≤ Iz` 就能同时满足 `I2 ≤ 1.45 Iz`。熔断器不一样：gG 熔断器的熔化系数在 1.6～1.9 之间，必须按 `In ≤ Iz / k3` 校核，`k3` 取 1.31（`In < 16 A`）或 1.10（`In ≥ 16 A`）。

换句话说，同样 100 A 的保护电器，熔断器要求的电缆载流量比断路器高约 10%。把两者混为一谈，是低压配电里常见的隐性欠配。

## 谐波让中性线变成载流导体

三相四线回路里，三次谐波不会相互抵消，而是在中性线里叠加。三次谐波含量 15%～33% 时，载流量要乘 0.86；超过 33% 时，中性线电流可能大于相电流，选型要按中性线电流来。

这时电缆标签里的 `4×S` 不再是“三根载流、一根备用”，而是四根都可能载流。把中性线当成零线来理解，是另一个常见的误区。

## 方案初选与施工图

本工具定位为方案初选。它可以快速回答“大概需要多大截面”“电压降是否成为瓶颈”“短路电流是否要求放大截面”“并联和成束后还够不够”等问题，但不能替代施工图设计。

正式设计还应结合：

- 电缆厂家的实际载流量数据与敷设条件；
- 现场环境温度、土壤热阻率、并列回路与通风条件；
- 保护电器的脱扣特性、上下级配合与 selective 协调；
- 谐波、不平衡负荷、中性线电流与 PE 导体截面；
- 当地供电部门与现行国家标准的强制要求。

施工图应由注册电气工程师按现行标准复核。
