# 技术说明

## 标准依据

本工具的计算框架参考以下现行标准：

- `GB/T 16895.6-2014` 低压电气装置 第 5-52 部分：电气设备的选择和安装 布线系统
- `GB 50054-2011` 低压配电设计规范
- `GB 51348-2019` 民用建筑电气设计标准
- `GB 50217-2018` 电力工程电缆设计标准
- `GB 55024-2022` 建筑电气与智能化通用规范

载流量修正和短路热稳定的具体表格、系数，正式设计应以标准原文和电缆厂家数据为准。

## 内置载流量表

内置表按 3 根负载导体整理，覆盖 A1、A2、B1、B2、C、D、E、F、G 九种敷设方式，以及铜/铝、PVC/XLPE 两种材料组合。

基准条件：

- 空气温度 30 ℃；
- 土壤温度 20 ℃；
- 土壤热阻率 2.5 K·m/W；
- 3 根负载导体。

单相和直流回路按 3 根负载导体表取值，结果偏保守。表中的数值为工程常用值，用于方案初选，不应直接作为施工图依据。

## 温度修正

空气敷设按 `GB/T 16895.6` 附录 B 的温度修正表取值，PVC 导体最高工作温度 70 ℃，XLPE 导体最高工作温度 90 ℃。直埋敷设改用土壤温度修正表。

当环境温度超出表格范围时，工具按边界值取值，并在结果中提示。

## 并列回路修正

并列回路数按 2～12 回取值，修正系数从 0.80 递减到 0.45。超过 12 回时按 0.45 取值并提示，建议分层敷设或补充计算。

## 导体电阻与电抗

导体电阻按最高工作温度修正：

```text
ρθ = ρ20 × [1 + α × (θ - 20)]
R = ρθ / S
```

铜：`ρ20 = 0.01724 Ω·mm²/m`，`α = 0.00393`；铝：`ρ20 = 0.02826 Ω·mm²/m`，`α = 0.00403`。

多芯电缆线路电抗默认取 0.08 Ω/km，可在页面中修改。

## 短路热稳定系数

常用 `k` 值：

| 导体 / 绝缘 | k |
| --- | --- |
| 铜 / PVC | 115 |
| 铜 / XLPE | 143 |
| 铝 / PVC | 76 |
| 铝 / XLPE | 94 |

短路热稳定按 `S ≥ Isc × √t / k` 校核，时间 `t` 取保护动作时间。

## 保护配合

自动匹配时，工具取不小于计算电流的最小标准断路器额定电流，并将保护配合作为选型约束之一：若 `In > Iz`，会继续放大截面，直到 `In ≤ Iz` 或达到 300 mm² 上限。

手动输入 `In` 时，工具按输入值校核 `Ib ≤ In ≤ Iz`。
