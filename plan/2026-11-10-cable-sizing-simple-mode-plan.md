# 工具 23 · 电缆选型「简易 / 专业」双模式方案

> 分支：`maint/tool-23-cable-sizing`
> 日期：2026-11-10
> 状态：已实施（2026-11-10，见 §10）
> 定位：方案初选；不改变专业模式的既有口径

## 1. 目标

在不新增路由、不改计算引擎的前提下，给电缆选型页加一个「简易」模式：

- 只暴露 9 个核心输入（输入方式与功率/电流算一组），其余参数按中性/假定值固定；
- 固定值在页面常驻可见，计算书与复制报告一并注明；
- 结果卡、7 步计算书、校核明细、符号联动保持完整；
- 「专业」模式字段、默认值与计算结果与现在完全一致。

非目标：不把简易模式做成“更乐观的选型”。所有固定值都是可解释的假定，且必须显示出来，避免用户把假定当成实测。

## 2. 已确认口径（2026-11-10）

| # | 决策项 | 结论 |
|---|---|---|
| 1 | 形态 | 同页「简易 / 专业」开关，不新建路由 |
| 2 | cosφ | 简易模式不保留，固定 1.00（阻性负荷假定），页面常驻提示 |
| 3 | 短路热稳定 | 保留校核，固定 Isc = 6 kA、t = 0.1 s，显示“按假定 6 kA” |
| 4 | 环境温度 | 固定 40 ℃ |
| 5 | 目标用户 | 方案初选 |

## 3. 现状

- 输入 `CableSizingInput` 共 32 个字段，三相交流常显约 20 个；
- 默认值集中在 `createDefaultInput()`（`cableSizing.ts:262`）；
- 页面为 2111 行单文件：3 个参数卡片 + 结果列 + 计算书 + 校核明细；
- 计算书来源枚举 `SymbolSource` 已有 `'default'`（`calculationSteps.ts:19`），线路电抗 0.08 已在用；
- 仓库已有模式开关先例：`SheetTemplatePage.vue:15` 的「新手引导 / 专业模式」，模式持久化在 `localStorage`；
- 引擎对非法输入的处理已锁在测试里：电压/长度/功率/cosφ/η/Kd/允许压降 ≤0 时直接返回 `null`（`cableSizing.spec.ts:168`）。

## 4. 设计

### 4.1 模式与状态

- `uiMode: 'simple' | 'professional'`，默认 `simple`（目标用户是方案初选）。
- 持久化：`localStorage['dls.cable-sizing.ui-mode.v1']`，读取失败静默忽略（对齐 `dls.sheet-template.v1` 的写法）。
- 两侧快照：`simpleInput` / `professionalInput` 各存一份，页面只绑定一份 reactive `form`。
  - 切换前：把当前 `form` 存回所属模式的快照；
  - 切换后：`Object.assign(form, 目标模式快照)`。
  - 效果：专业模式改过的 cosφ、In、启动校核等，切到简易再切回来不会丢。
- `重置` 按当前模式：简易 → `createSimpleInput()`；专业 → `createDefaultInput()`。
- 切到简易时 toast 说明“高级参数已按简易模式固定值参与计算”；切到专业时提示“可继续调整高级参数”；重置按模式给提示。

### 4.2 简易模式可见字段（9 个控件）

| 区块 | 字段 | 说明 |
|---|---|---|
| 01 系统与负荷 | 系统类型 | 三相 / 单相 / 直流 |
| 01 系统与负荷 | 标称电压 | 随系统联动默认值，可改 |
| 01 系统与负荷 | 负荷输入方式 | 按功率 / 按电流（保留，作为感性负荷的退路） |
| 01 系统与负荷 | 功率 P 或电流 Ib | 二选一，随输入方式显示 |
| 02 电缆与敷设 | 线路长度 L | 必填 |
| 02 电缆与敷设 | 导体材料 | 铜 / 铝，默认铜 |
| 02 电缆与敷设 | 绝缘材料 | PVC / XLPE，默认 XLPE |
| 02 电缆与敷设 | 敷设方式 | 9 选 1，默认 C |
| 03 校核条件 | 允许电压降 | 默认 5 %，保留 DC 3 % / 5 % 预设 |

### 4.3 简易模式固定值

| 参数 | 固定值 | 理由 / 语义 | 展示位置 |
|---|---|---|---|
| cosφ | 1.00 | 阻性假定；感性负荷请切专业或按电流输入 | 常驻提示 + 假定卡 |
| 效率 η | 1.00 | 不计效率损失 | 假定卡 |
| 需要系数 Kd | 1.00 | 按满载 | 假定卡 |
| 三次谐波 h3 | 0 % | 不计谐波与中性线电流 | 假定卡 |
| 并列回路数 | 1 | 单回路 | 假定卡 |
| 每相并联电缆 | 1 | 单根 | 假定卡 |
| 线路电抗 X | 0.08 Ω/km | 常量；计算书已标“默认 0.08” | 假定卡 + 计算书 |
| 短路电流 Isc | 6 kA | 假定值，不作短路计算 | 假定卡 + 校核行 |
| 保护动作时间 t | 0.1 s | 假定值 | 假定卡 + 校核行 |
| 断路器额定电流 In | 空（自动匹配） | 沿用现有 0/空 = 自动 | 假定卡 |
| 保护电器类型 | MCB | 微型断路器 | 假定卡 |
| 电机启动校核 | 关 | 不做启动压降 | 假定卡 |
| 环境 / 土壤温度 | 40 ℃ | 固定；直埋也按 40 ℃ 土壤，偏保守 | 假定卡 |
| 埋地间距 | 相触 | 仅 D 直埋，与默认一致 | 假定卡 |
| 土壤热阻率 | 2.5 K·m/W | 仅 D 直埋，基准值 | 假定卡 |
| DC 回路类型 | 负荷回路 | 仅标签，不影响计算 | 假定卡 |
| DC 导线制式 | 2 线 | 仅标签 | 假定卡 |
| DC 载流量源 | 国家标准表 | 厂家表在简易模式隐藏 | 假定卡 |
| DC 厂家表 | 空 | 回退标准表 | 不展示 |

说明：这些值都是引擎的合法输入，**不改 clamp、不改公式、不改 `createDefaultInput()`**；因此专业模式默认值仍是 cosφ 0.85 / η 0.9 / Kd 0.8 / 35 ℃。

### 4.4 页面呈现

- 页头 `page-actions` 左侧加 `.segmented`（复用现有样式）：「简易」「专业」。
- 简易模式下隐藏字段用 `v-if` 不渲染，不用 disabled 占位，减少视觉噪音。
- P3 底部加可折叠「简易模式假定」卡，按 4.3 表格逐条列出；折叠标题显示“固定值清单（随系统/敷设方式增减）”。
- 常驻提示（`notice` 风格）：
  > 简易模式按阻性负荷 cosφ=1、η=1、Kd=1 计算；电机、变压器等感性负荷请切「专业」模式，或改用「按电流」输入。
- 结果条 `result-strip` 增加「简易」徽标；结论区加一行：
  > 简易模式：cosφ=1、η=1、Kd=1、Isc 按假定 6 kA、t=0.1 s、环境 40 ℃、In 自动、MCB。
- 校核明细的热稳定行备注追加“（按假定 6 kA）”。

### 4.5 计算书与复制报告

- 7 步计算书保持全量，固定值按实际代入值显示（cosφ=1.00 等）；顶部加一行“模式：简易”。
- 复制计算书在“系统”行后插入：
  `模式：简易（cosφ=1、η=1、Kd=1、Isc=6 kA 假定、t=0.1 s、40 ℃、In 自动、MCB）`
- 专业模式不加这一行，报告格式与现在一致。

### 4.6 联动与边界

- 系统切换沿用现有 `watch`（电压随系统默认值）；切到 DC 的功率/长度启发式（30 kW→1 kW、80 m→30 m）保留，且仅当当前值等于默认值时才改。
- 敷设方式切到 D：温度保持 40 ℃（不再套土壤 20 ℃）；土壤热阻率 2.5、间距相触由简易默认值提供。
- 简易模式下不可见的参数仍参与计算，值来自 4.3；切到专业模式后这些字段显示为固定后的值，用户可改。
- 从专业切回简易会恢复简易快照（即固定值），这是模式语义，不是 bug；toast 需说明。

## 5. 明确不做（本轮）

| 项 | 原因 |
|---|---|
| 改引擎 clamp / 公式 / `createDefaultInput()` | 简易模式只是输入值组合，专业口径不动 |
| 独立简易路由 / 新工具条目 | 复制结果卡与计算书会分叉，维护成本高 |
| 表单字段持久化 | 页面现状不落盘；只持久化模式，避免“上次的假定值”被误当输入 |
| 计算书逐符号标注“默认”来源 | 需给 `buildCalculationSteps` / `buildCheckDetails` 增加 mode 参数并贯穿约 40 处 `symbol()` 调用；本轮用假定卡 + 模式行覆盖透明度，收益/成本不划算 |
| 场景模板（住宅 / 电机 / 照明） | 属产品功能，超出本轮 |
| 自动安全系数 / 简易结果强制升档 | 会引入第二套口径，与“同页开关”目标冲突 |
| 页面 e2e | 沿用上轮策略：引擎单测 + 手工截图 |
| 移动端专门适配 | 沿用现有响应式，本轮不改布局断点 |

## 9. 风险

- **默认模式改动**：首次进入从“全部字段”变为简易。如希望保持现状，把默认值改成 `professional` 即可，属一行调整。
- **cosφ=1 偏乐观**：电机负荷 cosφ≈0.8 时电流会被低估约 20 %。靠常驻提示 + “按电流”入口缓解，无法消除误用；如现场反馈明显，后续可加“负荷类型”单选（电机/照明/其他）自动带 cosφ，但不在本轮。
- **40 ℃ 对直埋偏保守**：土壤温度通常 20–25 ℃，结果可能大一到两档；文档与假定卡注明。
- **6 kA 是假定值**：不能替代短路电流计算；校核行、报告、计算书三处都写明“假定”。
- **模式语义误解**：用户可能以为切回简易会保留刚改的 cosφ；toast 与假定卡需明确“固定值由模式决定”。
- 简易默认与专业默认的截面恰好一致（均为 16 mm²，控制项均为短路热稳定），但这是当前参数下的巧合，不构成回归保证；测试锚点按 §7 第 2 条写。
